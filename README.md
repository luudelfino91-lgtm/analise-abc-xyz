# Análise ABC-XYZ + RFV — demonstração

Aplicação web estática com três estudos de caso (Farmácia, Cobrança e Marketing) sobre **dados sintéticos**, por Lucas Delfino.

- Versão: `1.0.0-rc.2` — integridade dos arquivos em `RELEASE_MANIFEST.json` (SHA-256).
- Os cálculos de ABC, XYZ, CV e RFV são feitos em pipeline Python e exportados em pacotes estáticos; a aplicação apenas lê e apresenta.
- Metodologia e limitações: tela "Metodologia" de cada mercado.
- Nenhum dado pessoal real; nenhuma transação de empresa real.
